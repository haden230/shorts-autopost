Privacy Policy

Shorts Autopost — last updated 5 September 2026

Shorts Autopost ("the tool") is a private, single-operator command-line program. It uploads videos its operator has made to that same operator's own YouTube and TikTok accounts. This policy explains what data the tool touches and what it does with it.

In short:

The tool has no users other than its operator. It collects no personal information from anyone, stores nothing on any server, and shares nothing with anyone. Everything it holds stays on the operator's own computer.

1. Information the tool accesses

When the operator authorises it, the tool accesses only their own account data:

  • Access and refresh tokens issued by YouTube and TikTok, which let it act on the operator's behalf.
  • Basic account information — the connected channel or account name, used to confirm it is posting to the right place.
  • Statistics for the operator's own videos — view counts, average view duration, audience retention, and subscriber changes.
  • Video files and their titles and descriptions, which the operator created and stored on their own computer.

The tool never requests or receives information about any other person's account, content, or activity.

2. Where information is stored

All of it stays on the operator's personal computer, in the tool's own folder. Tokens are written to local files (youtube_token.json, tiktok_token.json) that are excluded from version control.

There is no server, no database, and no cloud storage behind this tool. Nothing is transmitted anywhere except directly to YouTube's and TikTok's own official API endpoints, over HTTPS, in order to perform the upload or fetch the statistics that the operator asked for.

3. Information that is never collected

  • No personal information about any third party.
  • No email addresses, contact lists, or messages.
  • No location data.
  • No payment or financial information.
  • No behavioural tracking, cookies, advertising identifiers, or analytics.

4. Sharing

Nothing is shared, sold, rented, or disclosed to any third party. The tool has no advertising partners, no analytics providers, and no data processors. The only parties involved are the operator and the platforms they are posting to.

5. Retention and deletion

Tokens are kept only for as long as the operator uses the tool, and can be removed at any time by deleting the local token files. Access can also be revoked at the platform level:

  • YouTube / Google — Google Account permissions
  • TikTok — Settings and privacy → Security and permissions → Manage app permissions

Revoking access there immediately stops the tool from being able to act on the account.

6. Security

Tokens are stored in the operator's own user account on their own machine and are never checked into source control or copied elsewhere. All communication with platform APIs uses HTTPS. Because nothing is hosted remotely, there is no server that could be breached.

7. Children

The tool is not directed at children and is not usable by anyone other than its operator, who is an adult.

8. Compliance with platform rules

The tool uses the official YouTube Data API, YouTube Analytics API, and TikTok Content Posting API in accordance with each platform's developer terms and policies. It does not attempt to circumvent any platform restriction, rate limit, or review requirement.

9. Changes to this policy

If the tool's behaviour changes, this page will be updated and the date at the top revised.
